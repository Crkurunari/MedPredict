# MediPredict AI — Interactive school prototype

A beginner-friendly Streamlit app that lets you enter sample profile details, medical-history records and symptom notes, then generates an educational summary and downloadable report.

## Run locally (optional)
1. Install Python.
2. Open a terminal in this folder.
3. Run `pip install -r requirements.txt`
4. Run `streamlit run app.py`

## Publish online for a shareable link
1. Create a GitHub repository and upload `app.py` and `requirements.txt`.
2. Visit Streamlit Community Cloud and connect the repository.
3. Select `app.py` as the main file and deploy.

**Important:** This is an educational prototype, not a medical diagnostic or prediction tool. Use fictional sample data for demonstrations.
